**Software Developer** · Panama City, Panama

## About me

I build e-commerce platforms end to end: mobile apps, web storefronts and the APIs behind them.

I work across the whole development cycle, from architecture decisions through to production deployment, and I'm comfortable in small teams where you have to decide quickly and own the outcome.

**Areas I work in:**

- **Mobile** — iOS and Android apps with React Native
- **Web** — storefronts and dashboards with React, TypeScript and Angular
- **Backend** — REST APIs with NestJS and Node.js
- **Architecture** — multi-tenant systems, clean architecture and microservices

---

## What I've built

### Mobile apps

Customer apps for iOS and Android built with React Native. I handle the full cycle, from development to publishing and maintaining them on the App Store and Google Play.

### Multi-tenant platform

An architecture that runs two separate retail brands on a single platform and codebase. Both brands share the same features, so every improvement ships to both at once instead of being built twice.

### Web storefronts

Two online stores built with React and TypeScript using server-side rendering, so pages load fast and are properly indexed by search engines.

### Internal and operational tools

- **Admin dashboard** to manage products, pricing and orders.
- **Operational apps** for order pickers and delivery drivers, supporting the daily flow from preparing an order to delivering it.

### Payments

Integrated the payment methods used at checkout:

- Credit and debit cards with 3D Secure authentication (CyberSource)
- Yappy mobile payments
- Vouchers
- Cash on delivery

### Search, authentication and analytics

- **Search** — server-side product search with Typesense for fast, relevant results.
- **Authentication** — user sign-in with Firebase.
- **Analytics** — conversion tracking to understand how customers use the store.

### Architecture and delivery

- Architecture decisions and technical direction
- Code review
- CI/CD pipelines and deployments on AWS

### Legacy modernization

- Migrated legacy C# applications, improving performance and maintainability.
- Built Angular web apps applying clean architecture and reusable components.
- Built internal business apps with Microsoft PowerApps to streamline staff workflows.
